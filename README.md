# Roblox Dinosaur Egg Stealing Script

This Roblox script allows players to steal dinosaur eggs, which can be used to hatch dinosaurs or sell for money. The script includes a leaderboard system to track the number of eggs stolen, money earned, and rebirths, with data saved using Roblox's DataStoreService.

## Install

1. Open Roblox Studio and create a new place or open an existing one.
2. Insert a Script object into the ServerScriptService.
3. Copy the contents of the script into the Script object.
4. Save and test the game to ensure the egg stealing and leaderboard systems are working correctly.

## Use

1. Players can steal dinosaur eggs by interacting with the egg objects in the game.
2. The number of eggs stolen will be displayed on the leaderboard.
3. Players can sell eggs for money, which can be used to buy new dinosaurs or upgrades.
4. Players can earn rebirths by reaching certain milestones, which can unlock new features or dinosaurs.
